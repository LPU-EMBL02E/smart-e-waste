Design system

Minimalist neobrutalism in lavender, white and black. This page shows the colors, type, spacing, components and rules that the Student and Admin pages use. Every sample below is drawn with the shared wireframe.css, so what you see is what the pages use.

Color

Six base colors and three meaning colors. Do not add nearby shades for individual pages. White does most of the work: about three quarters of a screen should stay white.

Base colors

paper#FFFFFF Page background, fields, tables, ordinary panels
ink#000000 Text, borders, icons, hard shadows, focus outlines
lavender#C4B5FD Primary buttons and the one focal panel
lavender-strong#A78BFA Primary button hover and pressed fill
lavender-wash#F5F1FF Selected navigation and table headers
muted#595463 Supporting text on white or lavender-wash only

Meaning colors

success#166534 A server-confirmed successful or fulfilled result
warning#92400E Pending work, review or attention
danger#B91C1C Errors, failures and destructive actions

Lavender is a background color, not a text color. Put black text on lavender and lavender-strong, and keep the black border on lavender controls. Light theme only: there is no dark mode.

Typography

One native sans-serif family for the whole site, so there is no font download. The personality comes from heavy headings and strong numbers.

Feedback rules
Situation Treatment
Empty list A short heading and context. Offer a next step only if one exists.
Form success Inline message after redirect. No auto-dismiss.
Validation failure Error summary plus a message by each field. Keep safe input.
Server failure A clear heading and a recovery link. Never show a success state.
Dashboard refresh fails Keep the last values and their time. Do not replace them with zeros.
Motion Optional. 120–160 ms on transform and opacity only. Remove under reduced motion.

Use and avoid

Use and avoid
Use Avoid
Flat lavender fills, white surfaces, black text Gradients, glass effects, glow, textured backgrounds
A few hard shadows that set hierarchy Blurred shadows, floating cards everywhere
Straight edges with small, equal rounding Pill buttons, large rounded boxes, tilted cards
Real totals, units, dates and clear action labels Decorative counters, fake charts, invented impact claims
Quiet content with one strong focal point Sticker collages, starbursts, emoji navigation, bouncing UI

Accessibility baseline (WCAG 2.2 AA)

  • Text contrast at least 4.5 : 1. Control borders at least 3 : 1.
  • 44 × 44px targets for buttons, pagination and navigation.
  • Works at 320px wide and 200% text size, with no sideways page scroll.
  • Skip link, landmarks, visible focus and a logical tab order.
  • Status is written text; color and icons only support it.
  • Honors reduced motion and forced colors.
