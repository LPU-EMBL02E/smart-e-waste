Points rate

§7.4§5.7GET /admin/points-rate · POST /admin/points-rate · rules are versioned
points = floor(net_weight_g × points_per_gram). Saving closes the current rule (sets effective_to) and inserts a new one that takes effect at once. A session uses the rule in effect when it opened. A rule must be in effect for the bin to accept deposits.
